RPStore – A Modern Android Shopping App

RPStore is a small yet robust shopping app developed with modern Android technologies and clean architecture.  
This project serves as a **portfolio piece**, showcasing my Android coding style, structure, and use of industry-standard tools and patterns.

> 🧑‍💻 Still under active development. More features coming soon!

---

## 📱 Features

- 🏬 Product listing with categories
- ❤️ Favorite (wishlist) management
- 🛒 Add to cart and cart overview
- 🔍 Product detail view
- 🎯 MVI architecture for state management
- 📦 Local caching with Room DB
- 📡 Http request using Ktor
- 🎨 Built entirely with Jetpack Compose

---

 Tech Stack

| Tool / Library | Description |
|----------------|-------------|
| **Kotlin** | Primary language |
| **Jetpack Compose** | Modern declarative UI toolkit |
| **MVI Architecture** | Unidirectional data flow |
| **Koin** | Dependency Injection |
| **Room** | Local persistence |
| **Ktor** | HTTP client for networking |
| **Coroutines + Flow** | Asynchronous programming |
